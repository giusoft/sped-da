gFW - Versão 3.0

Objetivos:

- MÃínimo código final para o programador
- Abstração ainda maior do banco de dados (criar macros para select, insert, update e delete)
- Independência total da camada de apresentação
- Apresentação nativa para Desktop, iPhone, Celulares
- Melhor organização da camada de apresentação (CSS, imagens, í­cones, etc.)
- Melhor organização do software de terceiros
- Evitar passagens de parâmetros via POST ou GET, usar sessões para tudo
- Orientação a objeto
- Uso intenso de JSON para passagem de parâmetros
- Maior uso de AJAX
- Usa PDO ao invés do ADOdb
- Três modos de execução: Performance, Normal e Debug
- Possibilidade de uso de ferramentas externas: extjs, jquery, adodb, etc.
- Não será mais necessário gBegin e gEnd
- Exportação PDF, XLS, DOC, e CSV para qualquer página
- Oculta o código Javascript
- Botão enviar que se desabilita e mostra "Aguarde" automaticamente

- Login/logout
