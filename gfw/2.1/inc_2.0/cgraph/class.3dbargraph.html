3DBarGraph::SetBarFont() ^ Top | ^ Variables | ^ Methods
Set bar text font (1 to 5 are loaded by default on GD2, if you want others, you have to load them)
You can use these strings instead of int:
  1=x-small
  2=small
  3=normal
  4=large
  5=x-large

  Arguments:
        ( string | int ) $font
